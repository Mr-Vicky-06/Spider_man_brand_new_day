# 25 — SEO / Metadata

- **Title:** "Brand New Day — an original fan interactive experience"
  (or similar — avoid implying official status in the title itself, matching
  the brand-safety rule).
- **Description:** one or two sentences describing it as a fan-made cinematic
  scroll experience inspired by Spider-Man's visual language — explicit
  "fan-made" language in the meta description too, not just the footer.
- **Open Graph / Twitter card:** a single static hero image (Scene 06's finale
  frame is a natural choice — wide, resolved, represents the whole project
  well) with the same disclosure language in the OG description.
- **Favicon:** simple mark derived from the web-strand SVG system
  (`08-WEB-SYSTEM.md`), not a copyrighted spider-logo silhouette.
- **Structured metadata:** basic `WebSite`/`CreativeWork` JSON-LD, not
  `Movie`/`Organization` schema that could imply official affiliation.
- **Canonical strategy:** single-page experience, one canonical URL — no
  per-scene URLs/deep-linking planned (would conflict with the "one continuous
  timeline" experience philosophy in `03-EXPERIENCE-BIBLE.md`).
