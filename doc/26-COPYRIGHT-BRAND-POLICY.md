# 26 — Copyright / Brand Policy

## Classification
- **Original:** all frame sequences, the two Mask-scene images, the
  spider-sense shader, rain/grain effects, web-strand system, typography
  composition, copy — produced by/for this project.
- **Licensed (OFL fonts):** Bebas Neue, Inter — verified in `12-TYPOGRAPHY.md`.
- **Licensed (audio, per-clip):** Mixkit Free-License clips, Freesound
  CC0-filtered clips only — each entry requires a filled provenance block per
  `19-ASSET-MANIFEST-SPEC.md` before use.
- **Public-domain/open-source:** none currently planned as production assets
  (textures/HDRIs deferred per `assets/ASSET-INTELLIGENCE.md`; if adopted
  later, Poly Haven/ambientCG CC0 assets fall here).
- **Reference-only, never production:** any Spider-Man movie stills,
  promotional material, or official key art used during creative-direction
  mood-boarding. These never enter `public/` and are never redistributed.
- **Prohibited:** downloading/redistributing copyrighted movie footage,
  posters, stills, or music; scraping official promotional assets; any use of
  the official Marvel/Sony spider-logo mark.

## Positioning statement (used verbatim in footer + meta description)
"An original fan-made interactive experience inspired by the visual language
of Spider-Man: Brand New Day. Not affiliated with, endorsed by, or produced
by Marvel or Sony."

## Enforcement
The manifest's `provenance` block (mandatory per asset, `19-ASSET-MANIFEST-SPEC.md`)
is the mechanism, not a policy document read once and forgotten — an asset
without provenance literally can't be registered.
